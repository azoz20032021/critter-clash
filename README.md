لعبة **تفريم / نقر خاملة (Idle Clicker)** كاملة وجاهزة للنشر على **Google Play** و **App Store**،
مستوحاة من أسلوب *Clash of Critters* و *Hero Clicker*.

مبنية بـ HTML5 + JavaScript خالص (بدون أي مكتبات خارجية) ومغلّفة بـ **Capacitor** لتصبح
تطبيقاً أصلياً على أندرويد و iOS بنفس الكود.

## ✨ ما بداخل اللعبة

| النظام | التفاصيل |
|---|---|
| القتال | انقر لتضرب، ضربات حرجة، ضربة مزدوجة، ضرر/ث من فريقك، واكتساح تلقائي للمراحل الضعيفة |
| المراحل | ١٠ وحوش لكل مرحلة، **زعيم كل ٥ مراحل** بمؤقت ٣٠ ثانية، **مراحل لا نهائية فعلياً** |
| المخلوقات | ١٢ مخلوقاً مرسوماً يدوياً + **طبقات لا نهائية مولّدة** بعد المرحلة ٨٢، مكافأة **×٢ ضرر** عند المستويات المميزة |
| مختبر الطفرات | طوّر أي مخلوق: ٥ درجات ندرة، ١٢ صفة خاصة، ٤ عناصر، وشكل فريد — والطفرات تبقى بعد البعث |
| الحلبة (PvP) | قاتل لاعبين آخرين بأكواد فرق قابلة للمشاركة، أو خصوماً مولّدين — كؤوس ورتب وجواهر |
| الترقيات | ١٠ ترقيات بطل (ضرر، حرج، ذهب، مؤقت الزعيم…) |
| المهارات | ٥ مهارات فعّالة بأزمنة انتظار (هياج، نداء الحرب، حمى الذهب، صاعقة، انزلاق الزمن) |
| البعث (Prestige) | أرواح دائمة (+١٠٪ ضرر لكل روح) + **١٠ آثار أبدية** تُشترى بالأرواح |
| الاقتصاد | ذهب، جواهر، أرواح، صناديق كنز، معزّزات مؤقتة |
| الأوفلاين | أرباح أثناء الغياب حتى ٨ ساعات (قابلة للزيادة بالآثار) |
| الإنجازات | ٢٦ إنجازاً تمنح جواهر |
| الإعلانات | إعلانات مكافأة **اختيارية بالكامل** — ×٢ أرواح البعث، ×٢ صندوق، ×٢ أوفلاين، ×٢ ذهب، ×٢ ضرر، جواهر |
| اللغة | **عربي + إنجليزي** مع دعم كامل لـ RTL وتبديل فوري |
| الصوت | مؤثرات وموسيقى مولّدة برمجياً بـ WebAudio (صفر ملفات صوتية) |
| الرسوميات | كل الوحوش والمخلوقات **مرسومة برمجياً** على Canvas — حجم التطبيق صغير جداً وعدد الوحوش لا نهائي |
| الحفظ | حفظ تلقائي كل ١٥ ثانية + تصدير/استيراد كود الحفظ |

## 🚀 التشغيل السريع (على جهازك)

```bash
cd critter-clash

# 1) جرّبها في المتصفح فوراً — لا تحتاج أي تنصيب
npx serve www          # ثم افتح http://localhost:3000

# 2) نصّب الاعتماديات لبناء التطبيقات
npm install

# 3) أضف المنصات
npx cap add android
npx cap add ios        # يحتاج macOS + Xcode

# 4) بعد أي تعديل على www/
npx cap sync

# 5) افتح المشروع الأصلي
npx cap open android   # Android Studio
npx cap open ios       # Xcode
```

> **ملاحظة:** مجلدا `android/` و `ios/` يُولَّدان على جهازك بأمر `cap add`،
> ولهذا ليسا داخل هذه الحزمة (هذا هو الأسلوب القياسي في مشاريع Capacitor).

### الاختبارات ولقطات الشاشة

```bash
node tools/test-bignum.js   # ٤٦ فحصاً لطبقة الأرقام الضخمة
```

## 📺 نظام الإعلانات الاختيارية

كل الإعلانات في اللعبة **مكافأة اختيارية** — لا يوجد إعلان واحد يقاطع اللاعب.
النمط موحّد: **المكافأة الأساسية تُمنح أولاً، ثم يُعرض خيار المضاعفة.**
لو فشل الإعلان أو رفض اللاعب، لا يخسر شيئاً أبداً.

| المكان | العرض |
|---|---|
| **بعد البعث** | ×٢ على الأرواح المكتسبة |
| الصندوق المجاني (كل ٣٠ د) | ×٢ على الذهب/الجواهر |
| العودة بعد غياب | ×٢ على أرباح الأوفلاين |
| زر 🎁 في المعركة | ×٢ ذهب ٣٠ د، ×٢ ضرر ١٥ د، ٢٥ جوهرة، صندوق |

الدالة المسؤولة قابلة لإعادة الاستخدام في أي مكان جديد:

```js
CC.ui.offerDouble({
  icon: '👻',
  title: 'أرواح البعث',
  amount: '👻 57',
  onDouble: () => { g.souls += 57; }   // تُستدعى فقط عند اكتمال الإعلان
});
```

قاعدة مهمة مطبّقة: **لا يُعرض إعلانان متتاليان** — الصندوق الذي جاء من إعلان لا يعرض خيار مضاعفة بإعلان آخر.

## 💰 ربط إعلانات AdMob الحقيقية

اللعبة تعمل الآن بمعرّفات **اختبار** من Google، والإعلان يُحاكى في المتصفح.

1. أنشئ حساباً على [AdMob](https://admob.google.com) وسجّل تطبيقين (أندرويد + iOS).
2. أنشئ وحدة **Rewarded** لكل منصة.
3. افتح `www/js/ads.js` وضع معرّفاتك:

```js
const AD_UNITS = {
  android: { rewarded: 'ca-app-pub-XXXXXXXX/YYYYYYYY' },
  ios:     { rewarded: 'ca-app-pub-XXXXXXXX/ZZZZZZZZ' }
};
const USE_TEST_ADS = false;   // مهم: غيّرها إلى false قبل النشر
```

4. نصّب الإضافة: `npm i @capacitor-community/admob && npx cap sync`
5. **أندرويد** — أضف في `android/app/src/main/AndroidManifest.xml` داخل `<application>`:

```xml
<meta-data
    android:name="com.google.android.gms.ads.APPLICATION_ID"
    android:value="ca-app-pub-XXXXXXXX~AAAAAAAA"/>
```

6. **iOS** — أضف في `ios/App/App/Info.plist`:

```xml
<key>GADApplicationIdentifier</key>
<string>ca-app-pub-XXXXXXXX~BBBBBBBB</string>
<key>NSUserTrackingUsageDescription</key>
<string>نستخدم هذا لعرض إعلانات أكثر ملاءمة لك.</string>
```

## ♾️ كيف صارت المراحل لا نهائية

ثلاث مشاكل كان لازم تُحل، وكلها محلولة الآن:

**١. سقف الأرقام.** جافاسكربت يتوقف عند `1.8e308`، أي أن اللعبة كانت ستنكسر عند المرحلة ~١٤١٢.
الحل: `bignum.js` يخزّن كل قيمة كـ `m × 10^e` حيث الأس نفسه رقم عشري — السقف العملي `10^(1.7e308)`،
وهو رقم لا يمكن بلوغه بأي كمية لعب. الذهب والصحة والضرر والتكاليف كلها تمر عبره.

**٢. نفاد المخلوقات.** بعد المرحلة ٨٢ لم يعد هناك ما تشتريه. الحل: الطبقات تُولَّد إجرائياً بلا حد —
اسم مركّب بالعربي والإنجليزي، تكلفة ×٢٠، ضرر ×١٦، وشكل ولون من محرك الرسم نفسه.
المرحلة ٢٣٬٦٣١ تفتح الطبقة رقم ١٥٨١.

**٣. جدار البعث.** لو كانت مكافأة الأرواح ضعيفة، يتوقف التقدم عند حد ثابت مهما لعبت.
الرياضيات: صحة الوحش تنمو `10^0.22` لكل مرحلة، فيجب أن تنمو قوة البعث بنفس المعدل على الأقل.
الحل: `أرواح = 10 × (أفضل مرحلة − 9)^1.05` مع **كل روح تضرب الضرر في ١٫٠٦** (وليس +١٠٪ جمعاً).
النتيجة المقاسة فعلياً في `test-endless.js`:

| البعث | المرحلة | الأرواح | قوة الأرواح |
|---|---|---|---|
| ١ | ٨٦ | ٩٥٦ | ×1.56Sp |
| ٢ | ٢٦٧ | ٣٬٤٠٥ | ×228az |
| ٣ | ٧٢٥ | ١٢٬٩٢٩ | ×2.42ex |
| ٥ | ١٠٬٣٣٤ | ٢٩٥٬٠٢٣ | ×35.2djn |
| ٩ | **٢٣٬٦٣١** | ٩٧٧٬٠٦٢ | ×22.0xfh |

كل بعث يصل أعمق بـ ٢٫٥ ضعف تقريباً، بلا سقف.

**٤. وقت إعادة اللعب.** الوصول للمرحلة ٢٣٬٠٠٠ من جديد يستغرق وقتاً. حُلّت بأمرين:
«الاكتساح» (الضرر الفائض ينتقل تلقائياً للوحش التالي — حتى ٦٠ قتيلاً في الإطار الواحد)،
و«الخريطة القديمة» التي تبدأ بك من نسبة تصل إلى ٦٠٪ من أفضل مرحلة.

## 🧬 مختبر الطفرات

الفكرة التي أراها الأقوى تجارياً في اللعبة: **كل لاعب يملك مخلوقات لا يملكها أحد غيره حرفياً.**

بما أن محرك الرسم إجرائي، الطفرة تولّد شكلاً ولوناً فريدين، وتضيف:

| المكوّن | التفاصيل |
|---|---|
| الندرة | عادي ×١ · نادر ×١٫٧ · ملحمي ×٣ · أسطوري ×٥٫٥ · **خرافي ×١٠** |
| الصفة | ١٢ صفة: حادّ، جشِع، محظوظ، سريع، عملاق، ملتهب، شوكي، مصّاص، توأم، حارس، سام، عنقاء |
| العنصر | نار 🔥 · طبيعة 🌿 · ماء 💧 · رعد ⚡ (دورة أفضلية ×١٫٣٥) |
| التكلفة | ٢٥ جوهرة أول مرة، وترتفع ×١٫٤٥ مع كل إعادة تدوير لنفس المخلوق |

اللاعب يرى النتيجة قبل أن يقرر: **احتفظ بالجديد أم أبقِ الحالي**.
والطفرات **لا تُفقد عند البعث** — فهي التقدم بعيد المدى الذي يعيد اللاعب للعبة كل يوم،
وهي أيضاً ما يجعل الجواهر (أي الإعلانات) مرغوبة فعلاً.

## 🏆 الحلبة — قتال ضد لاعبين آخرين

بدون خادم وبدون تكلفة تشغيل، وبطريقة تصلح للنشر فوراً:

1. **كود الفريق**: فريقك يُضغط في نص قصير (~١٩٠ حرفاً) مثل `CC1eyJ2IjoxLCJu...`
2. اللاعب ينسخه ويرسله في واتساب أو تويتر
3. الصديق يلصقه ← تُحسب المعركة **حتمياً** من بصمة الكودين، فيرى الطرفان النتيجة نفسها بالضبط
4. ومن ليس لديه أصدقاء متاحون يقاتل خصوماً مولّدين بثلاث درجات صعوبة (سهل / متكافئ / بطل)

**محرك المعركة:** خمسة ضد خمسة، كل مخلوق له صحة وهجوم وسرعة مشتقة من قوته الحقيقية،
مع أفضليات العناصر ومفعول الصفات (ارتداد، امتصاص، ضربة مزدوجة، بعث العنقاء…).
القوى تُطبَّع لوغاريتمياً، فمعركة بين فريق قوته `10^300` وآخر `10^295` تبقى منطقية وممتعة.

**التوازن مقاس آلياً:** خصم أضعف بـ٤ أضعاف → اللاعب يفوز ٤٠/٤٠ · خصم أقوى بـ٤ أضعاف → ٠/٤٠ ·
خصم متكافئ → ٢٦/٤٠. والرتب: برونزي → فضي → ذهبي → ماسي → أستاذ → خرافي.

> **للتوسّع لاحقاً:** إضافة خادم بسيط يخزّن أكواد الفرق ويرتّبها = لوحة صدارة عالمية حقيقية،
> بدون تغيير أي سطر في محرك المعركة، لأن الكود والبذرة كافيان لإعادة إنتاج أي مباراة.

## ⚖️ ضبط التوازن

كل الأرقام في ملف واحد: **`www/js/data.js`**

```js
monsterHP(s)   = 10 × 1.57^(s-1)      // ويزداد الميل ×1.055 بعد المرحلة ٦٠
monsterGold(s) = 4  × 1.49^(s-1)
souls(s)       = 10 × (s − 9)^1.05    // وكل روح تضرب الضرر ×1.06
```

الفارق بين ١٫٥٧ و ١٫٤٩ هو ما يصنع **جدار البعث**: ارفع فارق الرقمين ليصبح التقدم أبطأ
ويصبح البعث ضرورياً أسرع، وقلّله ليصبح التقدم أسرع.

في المحاكاة الحالية (حفظ نظيف من الصفر):
- لاعب يشتري بذكاء (أفضل ضرر لكل قطعة ذهب) + يستخدم المهارات: **١٢ دقيقة ≈ المرحلة ٨٤ و ≈ ٩٢ روح**
- لاعب عادي يشتري عشوائياً بدون مهارات: **١٢ دقيقة ≈ المرحلة ٢٠ و ≈ ١٠ أرواح**

الفجوة بين الاثنين مقصودة: كفاءة الشراء هي «المهارة» في هذا النوع من الألعاب.

- تكلفة المخلوقات: `baseCost × costMult^level` (المضاعِف ١٫٠٨٦ → ١٫٠٩٧).
- مكافآت المستويات ×٢ عند: `MILESTONES = [10, 25, 50, 100, 200, 400, 800, 1600, 3000, 5000]`.
- الأرواح عند البعث: `floor((أفضل مرحلة − 4)^1.35 / 4)`.
